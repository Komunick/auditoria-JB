# Checklist de requisitos

- [x] Escopo de leitura distinguido da carga e das decisões particulares.
- [x] Papéis das colunas e significado de ZERADAS confirmados pelo usuário.
- [x] Layout, limites e recusas definidos sem inferência silenciosa.
- [x] Ausência, fórmula, duplicidade e zero inicial têm tratamento explícito.
- [x] Origem e identidade por aba/linha preservadas.
- [x] Autorização e única escrita permitida (auditoria de metadados) explícitas.
- [x] Contrato de contagens e estados de interface definido.
- [x] Compatibilidade, testes e publicação sem dados reais previstos.
- [x] Revisão independente antes da implementação; precisões de sem movimento,
  linha útil e recuperação de zero incorporadas em 28/10/2026.
