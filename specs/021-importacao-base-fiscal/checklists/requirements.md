# Checklist de requisitos

- [x] Escopo limitado à implementação local; nenhuma operação no Linear/produção.
- [x] Critérios verificáveis para leitura, preparação e confirmação separados.
- [x] Permissão sensível adicional, proprietário e sessão definidos.
- [x] Revalidação de arquivos, ausências e revisões cadastrais especificada.
- [x] Inclusão atômica, repetição e concorrência com resultado definido.
- [x] Preservação de existentes/ignorados e proveniência de todas as linhas.
- [x] Erros, limites temporários, limpeza e rede incerta tratados.
- [x] Testes antes do código, sintéticos, regressão e navegador previstos.
- [x] Sem nova dependência, serviço ou automatismo de carteira/tarefas.
