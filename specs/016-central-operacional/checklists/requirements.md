# Checklist de requisitos

- [x] Problema e usuários definidos; não exigir dados reais para construir a tela.
- [x] Referências oficiais separadas de adaptações propostas e recursos inexistentes.
- [x] Contagens, filtros, filas e diferença entre competência/vencimento explícitos.
- [x] Pendência de conferência e ausência de vencimento têm tratamento definido.
- [x] Escopo/autorização precedem agregação e não dependem do frontend.
- [x] Erro, vazio, carregamento, consulta antiga e falta de acesso previstos.
- [x] Exportação e detalhe reutilizam fluxo existente e respeitam os mesmos filtros.
- [x] Leitura sem mutação, schema preservado, sem dados reais no repositório.
- [x] Confirmação da importação preservada; etapa concluída exige sucesso do servidor.
- [x] Validação automatizada e visual prevista antes do encerramento.
