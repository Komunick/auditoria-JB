# Revisão dos requisitos antes da implementação

- [x] Cada proposta conserva origem e separa valores anteriores/efetivos.
- [x] Decisões de duplicidade explícitas, sem fusão ou associação por nomes.
- [x] Ausência estrutural de colunas e sem movimento preservados.
- [x] Consulta ao cadastro sem mutação nem migração, ausência/erro distintos.
- [x] Autorização cumulativa no servidor, no-store e limpeza em todo caminho.
- [x] Limites, pacotes hostis, fórmulas, campos e registros incompletos definidos.
- [x] UI sem carga, com estados concorrentes e encerramento de sessão definidos.
- [x] Aceite com dados sintéticos, regressão, evidências e sem produção.
