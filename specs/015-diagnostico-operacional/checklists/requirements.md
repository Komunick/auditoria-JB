# Checklist de requisitos

- [x] Derivado das duas pendências técnicas concretas da auditoria.
- [x] Comportamento observável e critérios de aceite definidos antes da implementação.
- [x] Identificação estável no processo e limitações explicitadas.
- [x] Logs sanitizados e acesso administrativo definidos.
- [x] Sem dados reais, nova infraestrutura ou alteração de regras fiscais.
- [x] TDD e regressão obrigatórios.
