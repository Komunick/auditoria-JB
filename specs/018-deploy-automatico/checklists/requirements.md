# Checklist de requisitos

- [x] Gatilho limitado à main e executor fora do checkout definidos.
- [x] Privilégios de root e de código da aplicação separados.
- [x] Backup, integridade, segredos e bloqueio sem rollback destrutivo definidos.
- [x] Convivência com cron e serviço existentes definida.
- [x] Testes isolados, origem pública e ausência de credenciais de CI previstos.
- [x] Ativação só após validação observável, sem presumir sucesso na VM.
